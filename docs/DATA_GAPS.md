# 数据库不足（FMP 源，美股 / 港股，2026-10-07）

按接口记：缺什么、现在怎么凑合、换什么源能解决。

## analyst-estimates（一致预期）

- 只给此刻的共识，不给历史快照。靠每天下载 + changelog 自己积累，开始记录之前的历史没有。
- 只给均值/最高/最低，没有单个分析师的数据。按分析师准确度加权的共识（A 股 `report_rc` 能做）美股港股做不了，没有替代源。
- 不标注一条预期覆盖几个月。半年报公司（港股约 60%）的"季度"预期混有半年量、全年量和复制出来的重复行。原样入库，使用时按财报表的披露节奏决定用不用；半年报公司不做 +1Q。
- 没人预测的指标填 0 而不是空，连人数不为 0 的也有（腾讯 2030 年度 25 人、eps 和 net_profit 都是 0）。入库时按人数为 0、或 eps 与 net_profit 同时为 0 置空。
- 未披露期的 date 是 12-30 / 03-30 这类近似日，披露后改为真实期末。入库取月末。

## income-statement / balance-sheet-statement / cash-flow-statement（财报）

- 没有日期参数，不能按发布日查全市场。用 latest-financial-statements 回看最近约 52 天的收录，更早退到逐股全量。第 4 档的 `*-bulk` 只作首选，失败回退逐股。
- 每期只有一个版本，没有原始版与修正版之分，`filingDate` 常等于期末日。A 股 estimates 用的"首次发布值打分"做不了。
- 银行的营收口径季度与年度不一致（如工行），净利润正常。

## historical-market-capitalization（每日市值）

- 市值 = 股价 × 最近一期财报股本：拆股日调整、财报发布日切换，季度内增发和回购反映不出来。`*_stock_indicator.total_share` 由它 ÷ 本地收盘价倒推，是同一个口径。
- tushare: `us_daily` 股本也是财报口径，每季只变两次——资产负债表的期末股本回填到期末日，10-Q 封面的流通股回填到封面截至日，其余日子不动；拆股当天正确。精度和"财报股本 + 拆股"自己算一样，而且它用了未来信息（期末日就填上 5 周后才公布的数），回测不如按公布日更新干净。**买 tushare 不能解决每日股本**（2026-10-17 实测）



## company-screener / etf-holdings（股票池）

- 列表类接口都没有证券类型字段，screener 的 `isAdr` 参数无效。美股池用 VONE 持仓 ∩ screener 近似 Russell 1000，混有十几只优先股、权证、交易所挂牌票据（如 BNH，Brookfield 的次级票据，screener 给它母公司的市值，走"外国公司 ≥ $2B"(原 $5B)进了池子）。tushare `us_basic` 有 `classify`。
- 没有恒生综合指数成分（能拿到持仓的只有盈富 2800 约 85 只、国企 2828、恒生科技 3033/3067）。港股池按"有 ≥2 人分析师预期"筛，约 500 只，一次刷新约 3600 次调用，表非空时不刷新。

## dividends（分红）

- 无分红年度、实施进度、税后金额、基准股本；早期记录缺宣告日/登记日/派息日。没有替代源。
- 增发、回购没有事件接口，只有现金流量表的季度金额。tushare 美股也没有。

## historical-chart（分钟线）

- 5 分钟线每次最多约 10 天（实测，无文档），1 分钟线需第 4 档。
- WRDS: 分钟线只有 TAQ 逐笔，没有指数，分钟线要自己聚合（2026-10-17）
- Bloomberg: 分钟线只回溯约 140 个交易日（2026-10-17）

## Sharadar（美股，2026-10-20 买了 Fundamentals 5 年档 1 个月 $19）

**接口**
- 直连 API `https://api.sharadar.com/v1.0/data/{表}`，不是 Nasdaq Data Link：sharadar.com 的 key 拿去调 `data.nasdaq.com` 会被拒(429 "account temporarily disabled")，账户本身没事。key 放请求头 `x-api-key`，env `SHARADAR_API_KEY`。
- 参数：`ticker`(可逗号多只)、`from`/`to`(两端包含，实测)、`fields`、`limit`(默认 10000 行，超了静默截断)、`format=csv`。周末、无此代码返回空表(只有表头)，不报错。
- **`from` 必须显式传**：文档说默认一年前，实测不一致——单只不传给满 5 年，多只一起不传每只只给最近 500 行(约 2 年)，都不报错。
- 整表用 `years=5|10|full` 下载 zip(302 跳转)，文档要求不要用 `skip` 翻页拉整表。
- 表结构公开、不用 key：`/schema/{表}?format=mysql`。字段字典在 `descriptions` 表。

**速率限制**（文档没写，从响应头实测）
- **同时最多 5 个请求**：第 6 个起返回 429 "Too many requests in progress"，带 `Retry-After: 5`。并行下载线程数不能超过 5(16 线程并发实测 3/16 被拒)。
- 每 **15 分钟 5000 次请求**，固定窗口，从窗口里第一个请求起算(18:04:48 发第一个 → `X-RateLimit-Reset` 18:19:48)，到点整体重置。
- 另有加权额度 25000/窗口：每次请求扣 `X-RateLimit-Cost`。按代码、日期取数据(含一次 9000 多行的多股票请求)都是 1；整表 zip 的消耗没测。
- 两个额度任何一个用完都要等重置。响应头 `X-RateLimit-Remaining` / `X-RateLimit-Weighted-Remaining` / `X-RateLimit-Reset`(unix 秒) 可直接读。
- 对我们：每只股票一次请求(5 年约 1255 行，远低于 10000 行上限)，加权额度用不满，只看 5000 次这一条。美股以后约 4000 只，全量、日更都是约 4000 次，一个窗口打得完；超了最多等 15 分钟。

**套餐与范围**
- 个人许可(含自己账户的研究、回测、自动交易)。Fundamentals 档：5 年 $19/月($199/年)、10 年 $29、完整历史(1998 起) $39($399/年)；Prices 档(股价表)另算，Bundle 两者都有。
- Fundamentals 档的表：`daily`、`fundamentals`、`actions`、`events`、`sp500`、`tickers`、`descriptions`。
- **5 年是滚动的**：时间序列表只到 2021-10-20，`from` 填得再早也不给。`tickers`、`descriptions` 是全量快照。
- 约 18,000 家美股公司，含已退市(TWTR 到 2022-10-27)、ADR、加拿大公司。

**`daily`：每日市值，每日股本 = 市值(百万美元) ÷ 不复权收盘价**（2026-10-20 付费 key 验证）
- 拆股当天调整：NVDA 2024-06-10 ×10、GOOGL 2022-07-18 ×20。
- 财报股数在 10-Q/10-K 申报日切换(AAPL 每季都是申报当天，和 `fundamentals` 的 `sharesbas` 一致)，不是报告期末，没有未来函数。两次财报之间的回购、增发反映不出来——美股没有任何源有。
- 多类股按全部类别折算合计：GOOGL 122.3 亿(A+B+C)、BRK.B 21.4 亿(按 B 股)。一家公司只在主类别代码下有行，GOOG、BF-A 这类次要类别查不到。
- 分拆不往回除：GE 分拆 GEHC(2023-01)、GEV(2024-04) 当天股本不跳。
- ADR 按 ADS 份数：TSM 51.9 亿(1 ADS = 5 股)、BABA 23.3 亿(1 ADS = 8 股)，与 ADR 股价同口径。
- 未细查：Visa 2024-07-24 股本降 5.3%，大概率是 B 类转换要约。
- 代码：FMP 的 `BRK-B` 对应 Sharadar `BRK.B`(`-` 换 `.`)。
- 回改(`lastupdated.gte` 可查最近改过的行，2026-10-13~19 实测)：一周 6931 行、214 只。我们股票池里只有 7 只、各 1 行，都是前一个交易日的数据次日定稿——日更从水位线前 2 天重拉已覆盖。整段回改(一只票一次改一年以上)集中在 KNDI、BTOC 这类小盘股，约 28 只/周，目前不在股票池；股票池扩到 4000 只后要再看。
- 不带 `ticker` 查询时，返回的日期最早只到 `to` 往前一年，`from` 填得更早也一样(带 `lastupdated` 的两次查询都是这样)；逐只带 `ticker` 查询时 5 年都给。

**其他表**
- `events`：8-K 申报日 + 事项代码，代码 22(业绩公告)就是美股真实的业绩发布日。对 FMP `us_income.filing_date`：20 只大盘股 398 个季度，FMP 记的是 10-Q/10-K 申报日，同一天 12%、晚 1–3 天 46%、**晚 4 天以上 42%(中位 14 天、最多 39 天)**；JPM、WMT、NKE、DE、ADBE 每季晚 2–3 周。暂不处理。
- `actions`：75 种公司行为——分红、拆股、分拆(比例)、代码变更、退市、并购对价、ADR 比例变化、交易所/行业代码变更。代码改名时 Sharadar 把整段历史挪到新代码下(旧代码查不到)，日更要靠它发现改名后重拉。复权因子不需要它(本地事件表已够)。
- `fundamentals`：ARQ/ARY/ART 按申报日索引、重述另起一条(point-in-time)；MR* 按报告期、随重述改写。`sharesbas` 是封面股数但按后来的拆股调过(NVDA 2024-04 季 246 亿)，真实股本从 `daily` 读。
- `sp500`：标普 500 历史调入调出(带被替换的代码)。
- 没有 Russell、分钟线、港股、不变的复权因子表。
