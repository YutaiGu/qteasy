# 数据库不足（FMP 源，美股 / 港股，2026-10-07）

按接口记：缺什么、现在怎么凑合、换什么源能解决。

## analyst-estimates（一致预期）

- 只给此刻的共识，不给历史快照。靠每天下载 + changelog 自己积累，开始记录之前的历史没有。
- 只给均值/最高/最低，没有单个分析师的数据。按分析师准确度加权的共识（A 股 `report_rc` 能做）美股港股做不了，没有替代源。
- 不标注一条预期覆盖几个月。半年报公司（港股约 60%）的"季度"预期混有半年量、全年量和复制出来的重复行。原样入库，使用时按财报表的披露节奏决定用不用；半年报公司不做 +1Q。
- 没人预测的指标填 0 而不是空，连人数不为 0 的也有（腾讯 2030 年度 25 人、eps 和 net_profit 都是 0）。入库时按人数为 0、或 eps 与 net_profit 同时为 0 置空。
- 未披露期的 date 是 12-30 / 03-30 这类近似日，披露后改为真实期末。入库取月末。

## income-statement / balance-sheet-statement / cash-flow-statement（财报）

- 没有日期参数，不能按发布日查全市场。用 latest-financial-statements 回看最近约 52 天的收录，更早退到逐股全量。第 4 档的 `*-bulk` 只作首选，失败回退逐股。
- 每期只有一个版本，没有原始版与修正版之分，`filingDate` 常等于期末日。A 股 estimates 用的"首次发布值打分"做不了。
- 银行的营收口径季度与年度不一致（如工行），净利润正常。

## historical-market-capitalization（每日市值）

- 市值 = 股价 × 最近一期财报股本：拆股日调整、财报发布日切换，季度内增发和回购反映不出来。`*_stock_indicator.total_share` 由它 ÷ 本地收盘价倒推，是同一个口径。tushare `us_daily_adj` / `hk_daily_adj`（约 2000 元/年）有交易所口径的每日股本、流通股本、换手率，上游 `hk_us_indicators` 表结构就是按它设计的，换源不改表。

## 复权

- 没有复权因子接口，只有复权价（每次除权整段重写）和 splits / dividends 事件；splits 把分拆也记成拆股。复权因子列空着。tushare `us_adjfactor` 一并解决。

## company-screener / etf-holdings（股票池）

- 列表类接口都没有证券类型字段，screener 的 `isAdr` 参数无效。美股池用 VONE 持仓 ∩ screener 近似 Russell 1000，混有十几只优先股、权证。tushare `us_basic` 有 `classify`。
- 没有恒生综合指数成分（能拿到持仓的只有盈富 2800 约 85 只、国企 2828、恒生科技 3033/3067）。港股池按"有 ≥2 人分析师预期"筛，约 500 只，一次刷新约 3600 次调用，表非空时不刷新。

## dividends（分红）

- 无分红年度、实施进度、税后金额、基准股本；早期记录缺宣告日/登记日/派息日。没有替代源。
- 增发、回购没有事件接口，只有现金流量表的季度金额。tushare 美股也没有。

## historical-chart（分钟线）

- 5 分钟线每次最多约 10 天（实测，无文档），1 分钟线需第 4 档；2000 年前后的分钟数据基本不存在。

## 其他

- 港交所期货、ETF 逐日持仓：FMP、tushare 都没有，只有港交所每日文件。
- 美元 3 个月前瞻利率：没有合适接口，无风险利率用 `us_treasury` 的 3 个月国债。
