# 数据库不足

## 美股 / 港股（FMP 源，2026-10-06）

### 凑合在用

- **复权因子 / 每日股本**（同一件事）：FMP 没有复权因子，也没有每日股本。现在 `*_stock_indicator.total_share` = FMP 每日市值 ÷ 本地日线收盘价，等于"最近一期财报股本"：拆股日调整、财报发布日切换，季度内增发和回购反映不出来。复权因子空着。
- **港股股票池**：无恒生综合指数成分接口（能拿到持仓的只有盈富 2800 约 85 只、国企 2828、恒生科技 3033/3067）。`hk_stock_basic` 按"有 ≥2 人的分析师预期"筛，约 500 只；一次刷新约 3600 次调用，表非空时不刷新。
- **美股股票池**：无干净的普通股列表，列表类接口都没有证券类型字段，screener 的 `isAdr` 参数无效。用 VONE 持仓 ∩ screener 近似 Russell 1000，混有十几只优先股、权证。
- **半年报公司的季度预期**：FMP 不标注预期覆盖几个月，半年报公司（港股约 60%）的"季度"预期混有半年量、全年量和复制出来的重复行。半年报公司只存年度预期，不做 +1Q。
- **一致预期历史**：FMP 只给此刻的共识，不给历史快照。靠每天下载 + changelog 自己积累，开始记录之前的历史没有。
- **财报全市场增量**：财报接口没有日期参数，不能按发布日查全市场；用 latest-financial-statements 回看最近约 52 天的收录，更早退到逐股全量。
- **财报版本**：每期只有一个版本，没有原始版与修正版之分，也没有发布日（filingDate 常等于期末日）。A 股 estimates 用的"首次发布值打分"在美股港股做不了。

### 以后买接口能解决

- **复权因子 + 每日股本 / 流通股本 / 换手率**：tushare `us_daily_adj` / `hk_daily_adj`（美股港股权限，约 2000 元/年）。上游 `hk_us_indicators` 表结构就是按它设计的，换源不用改表，`us_adjfactor` 一并补上。
- **证券类型**：tushare `us_basic` 有 `classify`（EQ/ADR/GDR/PF）。
- **财报全市场按日增量**：FMP 第 4 档的 `income-statement-bulk`。

### 没有替代来源

- **单个分析师的预测**：FMP 只给共识均值/最高/最低；tushare `report_rc` 只覆盖 A 股。美股港股的共识加权（按分析师准确度）做不了。
- **增发、回购事件**：FMP 只有现金流量表的季度金额；tushare 美股也没有事件表。
- **分红明细**：无分红年度、实施进度、税后金额、基准股本，早期记录缺宣告日/登记日/派息日。
- **分钟线**：5 分钟线每次最多约 10 天（实测，无文档），1 分钟线需第 4 档；2000 年前后的分钟数据基本不存在。
- **港交所期货、ETF 逐日持仓**：FMP、tushare 都没有，只有港交所每日文件。
- **美元 3 个月前瞻利率**：FMP 没有合适的接口，无风险利率用 `us_treasury` 的 3 个月国债。
